# Щастя CRM

Клієнтська MVP-панель для кейтерингу (аналог можливостей Caiter): замовлення з кошторисом, публічне КП, календар, каталог, клієнти, закупки, кухня, звіти.

Дані зберігаються в `localStorage` (Zustand persist). Бекенд не потрібен.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте адресу з терміналу (зазвичай `http://localhost:5173`).

## Збірка

```bash
npm run build
npm run preview
```

## Модулі

- **Огляд** — активні замовлення, виручка, швидкі дії
- **Замовлення** — фільтри, статуси, кошторис, платежі, маржа
- **Публічне КП** — `/p/:id` для опублікованих замовлень
- **Календар** — події за місяцем
- **Каталог** — страви / послуги / інгредієнти
- **Клієнти** — контакти та компанії
- **Закупки** — списки з інгредієнтів, статуси planned/ordered/received
- **Кухня** — друкований лист завдань `/orders/:id/kitchen`
- **Звіти** — виручка, прибутковість, ABC
- **Налаштування** — компанія, менеджери, скидання демо

Глобальний пошук: `Ctrl/Cmd + K`.

## Стек

Vite · React · TypeScript · react-router-dom · Zustand (+ persist) · date-fns · nanoid
