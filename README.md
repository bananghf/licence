# Щастя CRM

Власна операційна панель для кейтерингу з **функціональним паритетом** до Caiter-класу CRM (замовлення, КП, закупки, кухня, звіти). Це **не** візуальна копія Caiter і без їх бренду/асетів — продукт «Щастя CRM», демо під «Щастя Є» (Вінниця).

Дані в `localStorage` (`shastya-crm-v2`).

## Запуск

```bash
npm install
npm run dev
```

Відкрийте URL, який покаже Vite (зазвичай `http://localhost:5173`).

## Збірка

```bash
npm run build
npm run preview
```

## Модулі vs Caiter (публічні docs / help.caiter.ru)

| Модуль Caiter | Статус | У Щастя CRM |
|---------------|--------|-------------|
| Замовлення / смети / КП | **have** | Список, фільтри, смета, знижки/націнки, публікація `/p/:id`, CSV |
| Варіанти смет (Про+) | **partial** | Розділи сметі є; мульти-варіанти «Стандарт/Преміум» — ні |
| Календар | **have** | Місячна сітка подій |
| Каталог товари/послуги/інгредієнти | **have** | CRUD + **ТТК (склад страв)** |
| Клієнти контакти/компанії | **have** | Вкладки контакти / компанії |
| Закупки з ТТК | **have** | Генерація з замовлень по складу, CSV |
| Завдання кухні / внутрішня смета | **have** | Черга `/kitchen` + друк листа з ТТК |
| Платежі / рахунки | **have** | На замовленні + рахунки в налаштуваннях |
| Звіти / рентабельність / ABC | **have** | Виручка, маржа, ABC |
| Меню-інжиніринг | **have** | Зірки / коні / загадки / собаки |
| Глобальний пошук | **have** | Ctrl/Cmd+K |
| Налаштування | **have** | Бренд, фінанси, менеджери |
| Bitrix24 / PDF-PPT / мульти-юзер / склад | **missing** | Потребують бекенд / інтеграції |

Гаряча клавіша пошуку: **Ctrl/Cmd + K**.
