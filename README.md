# Щастя Є

Односторінковий сайт кейтерингу «Щастя Є» (Вінниця). Текст, структура і фото зібрані з презентації: напрямки, фуршет, банкет, солодка станція, гастро-шоу, бар, кава-паузи, ланчі, додаткові послуги та контакти.

Відкрити локально:

```bash
python3 -m http.server 4173
```

Потім перейти на [http://127.0.0.1:4173](http://127.0.0.1:4173).
