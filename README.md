# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця): послуги, заявка, SEO, Telegram-бот.

```bash
npm install
npm run build
npm start
```

Локально: http://127.0.0.1:4173  

## Cloudflare

Див. `CLOUDFLARE.md`. Коротко: D1 + 2 секрети (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_PASSWORD`), без `DATABASE_URL`.

Бот: `/start` → пароль → заявки. Невірний пароль — повідомлення про помилку. `/stop` — відписка.
