# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця): послуги, заявка, SEO.

```bash
npm install
npm run build
npm start
```

Сайт: http://127.0.0.1:4173  

## Telegram-бот для заявок

1. Секрет `TELEGRAM_BOT_TOKEN` — токен бота (один раз)
2. Секрет `TELEGRAM_BOT_PASSWORD` — пароль доступу (можна також `TELEGRAM_JOIN_CODE`)
3. Замовник відкриває бота → `/start` → пише пароль → заявки йдуть йому
4. `/stop` — вимкнути сповіщення на цьому акаунті

Посторонні без пароля заявки не отримають. Новий телефон/акаунт — знову `/start` і пароль.

Опційно: `TELEGRAM_CHAT_ID` як запасний отримувач.
