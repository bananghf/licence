# Щастя CRM

Операційна панель для кейтерингу (аналог Caiter з власним брендом): комерційні пропозиції, замовлення, календар подій, каталог, клієнти, закупки, платежі та звіти.

Дані зберігаються локально в браузері (`localStorage`). Демо-набір — кейтеринг «Щастя» (Вінниця).

## Запуск

```bash
npm install
npm run dev
```

Відкрийте URL, який покаже Vite (зазвичай `http://localhost:5173`).

## Збірка

```bash
npm run build
npm run preview
```

## Основні розділи

| Розділ | Що робить |
|--------|-----------|
| Огляд | KPI, найближчі події, швидкі дії |
| Замовлення | Фільтри, кошторис, платежі, публікація КП |
| КП `/p/:id` | Клієнтський перегляд опублікованої пропозиції |
| Календар | Місячна сітка подій |
| Каталог | Страви / послуги / інгредієнти |
| Клієнти | Контакти та компанії |
| Закупки | Списки + генерація з замовлень |
| Звіти | Виручка, маржа, ABC-аналіз |
| Налаштування | Бренд, менеджери, скидання демо |

Гаряча клавіша пошуку: **Ctrl/Cmd + K**.
