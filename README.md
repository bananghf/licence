# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця): послуги, заявка, SEO.

```bash
npm install
npm run build
npm start
```

Сайт: http://127.0.0.1:4173  

## Секрети Cursor

- `TELEGRAM_BOT_TOKEN` — токен бота (один раз)
- `TELEGRAM_JOIN_CODE` — код доступу: людина пише його боту (`/start КОД` або просто код) і починає отримувати заявки
- `TELEGRAM_CHAT_ID` — необов’язково: запасний chat id

Контент сайту — у `content/default.json`. Заявки з форми йдуть у Telegram підписаним користувачам.
