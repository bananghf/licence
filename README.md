# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця): послуги, процес замовлення, галерея, питання і форма заявки. Тексти й телефон змінюються в адмінці `/admin`, без правки коду.

```bash
npm install
ADMIN_PASSWORD='довгий-пароль' npm start
```

Сайт: [http://127.0.0.1:4173](http://127.0.0.1:4173). Адмінка: [http://127.0.0.1:4173/admin](http://127.0.0.1:4173/admin).

Пароль береться лише зі змінної `ADMIN_PASSWORD`. Якщо її немає, сайт відкривається, а збереження в адмінці вимкнене. На хостингу Cursor цей пароль додається як секрет із тією самою назвою.

Заявки з форми зберігаються (Postgres або тека `data/`) і одразу йдуть у Telegram, якщо задані секрети `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Без них сайт працює, а повідомлення в Telegram просто пропускаються.
