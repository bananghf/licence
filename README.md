# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця) на Next.js: послуги, заявка, SEO і адмінка.

```bash
npm install
npm run build
ADMIN_PASSWORD='ваш-пароль' npm start
```

Сайт: http://127.0.0.1:4173  
Адмінка: http://127.0.0.1:4173/admin.html  

Пароль — змінна `ADMIN_PASSWORD` (секрет у Cursor). Заявки йдуть у Telegram, якщо задані `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.
