# Щастя Є

Сайт кейтерингу «Щастя Є» (Вінниця): послуги, заявка, SEO і адмінка.

```bash
npm install
npm run build
ADMIN_PASSWORD='ваш-пароль' npm start
```

Сайт: http://127.0.0.1:4173  
Адмінка: http://127.0.0.1:4173/admin.html  

## Секрети Cursor

- `ADMIN_PASSWORD` — пароль адмінки
- `TELEGRAM_BOT_TOKEN` — токен бота (один раз)
- `TELEGRAM_JOIN_CODE` — код доступу: людина пише його боту (`/start КОД` або просто код) і починає отримувати заявки
- `TELEGRAM_CHAT_ID` — необов’язково: старий одиночний chat id як запасний отримувач

Chat id більше не треба прописувати вручну для кожної людини. У боті: `/stop` — відписатись. В адмінці видно список підписаних і можна видалити.
